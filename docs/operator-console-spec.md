Спроектируй веб-приложение — внутреннюю админ-панель («operator console») 
для владельца SaaS-платформы, управляющей десятками бизнес-клиентов. 
Это НЕ клиентский интерфейс, это инструмент для владельца SaaS и его команды 
поддержки, чтобы контролировать все подключённые бизнесы в одном месте.

=== КОНТЕКСТ ПРОДУКТА ===
SaaS-платформа заменяет клиентам стек CRM + омниканальный чат + управление 
складом/заказами + сайт. Каждый клиент — отдельный бизнес (в основном 
товарный ритейл: магазины, посуда, одежда). Модель: ранний доступ ~5–7k ₽/мес 
для первых 5 клиентов, целевой тариф 70k ₽/мес + 15k разово за интеграцию.
Ключевая внутренняя метрика — часы, потраченные на онбординг и поддержку 
каждого клиента (это метрика готовности к масштабированию).

=== ЦЕЛЕВОЙ ПОЛЬЗОВАТЕЛЬ ===
Владелец SaaS + 1–2 человека команды. Заходит утром, хочет за 30 секунд 
понять: всё ли живо, кто платит, кто в онбординге, где горит.

=== ЭКРАНЫ ===

1. DASHBOARD (главная)
   - Верхний ряд KPI-карточек: MRR, ARR, активных клиентов, клиентов в 
     онбординге, средний health score, часов потрачено за неделю.
   - График MRR и количества клиентов за 6 месяцев.
   - Виджет «Нужно внимание»: клиенты с падающим health score, 
     просроченные платежи, застрявшие в онбординге, упавшие интеграции.
   - Виджет «Ближайшие события»: продления, окончания фиксированной 
     льготной цены, дедлайны задач.

2. КЛИЕНТЫ (список бизнесов)
   - Таблица: название бизнеса, ниша, тариф (полный / ранний доступ / 
     кастомный), статус (лид / онбординг / активен / пауза / отток), 
     MRR, health score (0–100 с цветовой шкалой), дата подключения, 
     часов за месяц, ответственный менеджер.
   - Фильтры: ниша (товарный / услуги), статус, тариф, менеджер.
   - Поиск. Массовые действия.
   - Бейджи «ранний доступ» и «фиксированная цена» — визуально отдельно, 
     чтобы не путать со стандартными тарифами.

3. КАРТОЧКА КЛИЕНТА (детальная страница одного бизнеса) — самый важный экран
   Левая колонка — сводка: логотип, контакты владельца, ниша, размер, 
   тариф, MRR, статус, дата подключения, ответственный.
   Основная область — вкладки:
   - «Обзор»: health score с разбивкой (активность, интеграции, платежи, 
     обращения в поддержку), последние события, заметки.
   - «Онбординг»: чек-лист этапов (анализ бизнеса → интеграции → 
     обучение → запуск), для каждого этапа — статус, ответственный, 
     потраченные часы.
   - «Интеграции»: карточки подключений — 1С, МойСклад, Ozon, 
     Wildberries, СДЭК, WhatsApp, Telegram, сайт. У каждой: статус 
     (работает / ошибка / не подключена), последняя синхронизация, 
     логи ошибок.
   - «Биллинг»: текущий тариф, история платежей, следующее списание, 
     скидки, задолженности, кнопка «выставить счёт».
   - «Использование»: сколько сотрудников заведено у клиента, объём 
     сделок/заказов/сообщений за период, топ-функций.
   - «Часы»: тайм-трекинг работы команды над этим клиентом с разбивкой 
     по типам работ (интеграция / поддержка / доработка).
   - «Задачи и тикеты».
   - «История общения»: заметки, звонки, письма.

4. ОНБОРДИНГ PIPELINE (канбан)
   - Колонки: Лид → Демо проведена → Договор → Онбординг → Запуск → Активен.
   - Карточки клиентов перетаскиваются между колонками.
   - На карточке: логотип, название, ниша, дней в текущем статусе, 
     ответственный, следующее действие.

5. БИЛЛИНГ И ФИНАНСЫ
   - MRR / ARR / средний чек / отток по деньгам.
   - График cohort retention.
   - Таблица всех платежей.
   - Отдельный блок «Ранний доступ»: список клиентов на льготной цене, 
     дата фиксации, потенциальный MRR при переходе на полный тариф.

6. МЕТРИКИ ПРОДУКТА
   - Часы на клиента (среднее, тренд) — с целью «сокращать со временем».
   - Время онбординга (от договора до запуска).
   - Health score распределение.
   - Retention, отток, NPS.

7. ИНТЕГРАЦИИ (обзор по всем клиентам)
   - Тепловая карта: строки — клиенты, столбцы — интеграции, цвет — статус.
   - Список последних падений с деталями.

8. НАСТРОЙКИ
   - Тарифы и скидки.
   - Команда и роли.
   - Шаблоны онбординга (чек-листы).

=== ДИЗАЙН ===
Стиль: современный, спокойный, data-dense (много информации на экране, 
но без визуального шума). Ориентир — Linear, Attio, Vercel Dashboard, 
Stripe Dashboard. Не Битрикс.

- Светлая тема по умолчанию + тёмная.
- Сайдбар слева с иконками разделов, свернётся до узкой полосы.
- Топбар: глобальный поиск (⌘K), уведомления, профиль.
- Типографика: Inter или похожий гротеск. Заголовки не крупнее нужного.
- Цвета: нейтральный серый фон, один акцентный цвет (сине-фиолетовый), 
  семантические цвета (зелёный/жёлтый/красный) только для статусов и 
  health score.
- Компоненты: карточки со скруглением 8–12px, тонкие бордеры вместо 
  жирных теней, таблицы с sticky-заголовком и построчным hover.
- Иконки — lucide или аналогичный тонкий набор.
- Плотность — компактная, но с воздухом. Строка таблицы ~40–44px.
- Мобильной версии не надо — только десктоп (min 1280px).

 Приоритет экранов для проработки: Dashboard → Карточка клиента → 
Список клиентов → Онбординг pipeline. Остальные — как каркас.
